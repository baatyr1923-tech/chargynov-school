Сабактын максаты

2-чейректе робот техникасы, жасалма интеллект, Arduino жана Microsoft Office боюнча алган билимдерди бышыктоо жана текшерүү.

Күтүлүүчү натыйжалар

  • Роботтордун түрлөрүн жана колдонулуу багыттарын айырмалайт.
  • Arduino компоненттерин жана кодун түшүндүрөт.
  • ЖИнин робот техникасындагы ролун билет.
  • Word, Excel жана графикалык объекттер менен иштөөнү кайталап чыгат.

Кайталоо: робот техникасы жана жасалма интеллект

ТүшүнүкАныктама
РоботПрограмма боюнча тапшырмаларды аткаруучу түзүлүш.
СенсорАйлана-чөйрөдөн маалымат алуучу түзүлүш.
КонтроллерМаалыматты иштетип, түзүлүштөрдү башкаруучу бөлүк.
Аткаруучу механизмРоботтун кыймылын же аракетин аткаруучу бөлүк.
Жасалма интеллектМаалыматтарды талдап, акылдуу тапшырмаларды аткарууга жардам берген технология.

Кайталоо: Arduino жана программалоо

  • Arduino Uno — электрондук түзүлүштөрдү башкаруучу такта.
  • Breadboard — схемаларды убактылуу чогултуучу такта.
  • LED — жарык чыгаруучу диод.
  • Резистор — электр тогун чектөөгө жардам берет.
  • Мотор — кыймыл жаратуучу түзүлүш.
void setup() {
  pinMode(13, OUTPUT);
}
void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}

Программа 13-пиндеги LEDди бир секунд күйгүзүп, бир секунд өчүрөт. loop() ичинде болгондуктан процесс кайталанат.

Кайталоо: Microsoft Office

ПрограммаКызматы
WordТексттик документтерди түзүү жана форматтоо.
ExcelСандар, таблицалар жана эсептөөлөр.
PowerPointПрезентация түзүү.
AccessМаалыматтар базасын башкаруу.

Word: Ctrl+B — калың жазуу, Ctrl+C — көчүрүү, Ctrl+V — жайгаштыруу, Ctrl+S — сактоо.

Excel формуласы = белгиси менен башталат. SUM — сумма, AVERAGE — орточо маани, MAX — эң чоң сан, MIN — эң кичине сан.

Практикалык текшерүү тапшырмалары

1. Роботтун алгоритми: «Робот алдыга кыймылдайт → сенсор тоскоолдукту байкайт → контроллер маалыматты иштетет → мотор токтойт» тартибин түшүндүргүлө.

2. Arduino: LEDди 2 секунд күйгүзүп, 1 секунд өчүрүүчү код түзгүлө. setup() жана loop() функцияларын түшүндүргүлө.

3. Word: чакан текст түзүп, баш аталышын ортого тегиздеп, калың кылып форматтагыла.

4. Excel: беш шарттуу сан киргизип, SUM жана AVERAGE функциялары менен суммасын жана орточо маанисин тапкыла.
