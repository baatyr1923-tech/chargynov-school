Arduino кодун түзүү

2-чейрек · 5-сабак

9-класс 2-чейрек 45 мүнөт

Сабактын максаты

Arduino IDE программалоо чөйрөсү жана коддун негизги түзүлүшү менен таанышып, жөнөкөй программа түзүү.

Күтүлүүчү натыйжалар

  • Arduino IDE программасынын кызматын түшүндүрөт.
  • setup() жана loop() функцияларын айырмалайт.
  • pinMode(), digitalWrite(), delay() буйруктарын колдонот.
  • LEDди күйгүзүп-өчүрүүчү программа түзөт.

Arduino IDE деген эмне?

Arduino IDE — Arduino такталары үчүн программа жазууга, текшерүүгө жана микроконтроллерге жүктөөгө арналган программалык чөйрө.

  1. Код жазуу.
  2. Программанын тууралыгын текшерүү.
  3. Ката болсо, оңдоо.
  4. Программаны Arduino тактасына жүктөө.

Arduino программасынын түзүлүшү

setup() функциясы программа башталганда бир жолу аткарылат. Пиндердин иштөө режимин жана баштапкы параметрлерди аныктайт.

loop() функциясы setup() бүткөндөн кийин кайра-кайра аткарылып турат. Негизги аракеттер ушул жерге жазылат.

void setup() {
  // Баштапкы орнотуулар
}

void loop() {
  // Кайталануучу буйруктар
}

Негизги буйруктар

БуйрукКызматы
pinMode()Пиндин иштөө режимин аныктайт.
digitalWrite()Пинге HIGH же LOW сигналын берет.
delay()Белгиленген убакытка күттүрөт.
HIGHЖогорку деңгээлдеги санариптик сигнал.
LOWТөмөн деңгээлдеги санариптик сигнал.
OUTPUTСигнал чыгаруучу режим.
pinMode(13, OUTPUT);       // 13-пинди чыгаруучу кылуу
digitalWrite(13, HIGH);    // Жогорку сигнал берүү
digitalWrite(13, LOW);     // Төмөн сигнал берүү
delay(1000);               // 1 секунд күтүү

Практикалык иш: LEDди күйгүзүү жана өчүрүү

Керектүү каражаттар: Arduino Uno, LED, 220–330 Ом резистор, breadboard, jumper зымдары жана USB кабель.

Тышкы LEDдин узун бутун резистор аркылуу 13-пинге, кыска бутун GNDге туташтыргыла. Arduino Uno тактасынын өзүндөгү 13-пинге байланышкан орнотулган LEDди да колдонууга болот.

int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH);
  delay(1000);

  digitalWrite(ledPin, LOW);
  delay(1000);
}

Программа LEDди 1 секунд күйгүзүп, 1 секунд өчүрөт. loop() ичинде болгондуктан аракет кайра-кайра кайталанат.

Программаны тактага жүктөө

  1. Arduino IDE программасын ачуу.
  2. Такта аркылуу USB кабель менен компьютерге туташтыруу.
  3. Arduino Uno тактасын тандоо.
  4. Туура портту тандоо.
  5. Verify баскычын басып кодду текшерүү.
  6. Upload баскычын басып программаны жүктөө.
  7. LEDдин күйүп-өчүшүн байкоо.
Туташтырууну өзгөртүүдөн мурда кубатты өчүргүлө. LEDди резисторсуз тышкы чынжырга кошпогула.

Практикалык тапшырмалар

1. Эки delay(1000) маанисин delay(500) кылып өзгөрткүлө. Күйүп-өчүү ылдамдыгы кандай өзгөрөт?

2. LEDди 2 секунд күйгүзүп, 500 миллисекунд өчүрүүчү код жазгыла.

3. Коддогу катаны тапкыла: delay(1000) сабынын аягында чекиттүү үтүр жетишпесе, аны кошкула.

Жыйынтыктоо жана үй тапшырмасы

setup() менен loop() функцияларынын айырмасы эмнеде? delay(1000) эмнени билдирет? LEDди күйгүзүүчү буйрук кайсы?

Үй тапшырмасы: Arduino программасынын түзүлүшүн кайталап, LEDди 2 секунд күйгүзүп, 1 секунд өчүрүүчү кодду жазып келүү.
