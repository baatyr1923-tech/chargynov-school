Сабактын максаты

Окуучулар Python тилиндеги функция түшүнүгүн өздөштүрүшөт, функцияны аныктап жана чакырууну үйрөнүшөт. Аргументтерди, локалдык жана глобалдык өзгөрмөлөрдү, return операторун жана lambda-функцияларды колдоно алышат.

Күтүлүүчү натыйжалар

  • Функциянын эмне үчүн колдонуларын түшүндүрөт.
  • def ачкыч сөзү менен функция түзүп, аны чакырат.
  • Параметр менен аргументтин айырмасын билет.
  • Локалдык жана глобалдык өзгөрмөлөрдү айырмалайт.
  • return аркылуу функциядан маани кайтарат.
  • Жөнөкөй lambda-функция түзөт.

1. Функция деген эмне?

Функция — белгилүү бир милдетти аткарган, аты бар жана программада кайра-кайра колдонууга боло турган код бөлүгү. Функциялар программаны бөлүктөргө бөлүп, кодду түшүнүктүү жана кайталап колдонууга ыңгайлуу кылат.

Мисал: эки сандын суммасын эсептөөчү функцияны бир жолу жазып, аны ар башка сандар менен көп жолу чакыра алабыз.

Функцияны аныктоо жана чакыруу

def salamdash():
    print("Саламатсыңарбы!")

salamdash()

Бул жерде:

  • def — функцияны аныктоочу ачкыч сөз.
  • salamdash — функциянын аты.
  • () — параметрлер жазылуучу кашаалар.
  • : — функциянын денеси башталарын билдирет.
  • Ичкери жылдырылган команда функциянын денесине кирет.
  • salamdash() — функцияны чакырат.

2. Функциялар жана алардын аргументтери

Функция маалыматты параметрлер аркылуу кабыл алышы мүмкүн. Параметр — функцияны аныктоодо кашаанын ичинде көрсөтүлгөн өзгөрмө. Аргумент — функцияны чакырганда ошол параметрге берилген чыныгы маани.

def koshuu(a, b):
    print(a + b)

koshuu(4, 6)
koshuu(10, 20)

Натыйжасы:

10
30

Бул мисалда a жана b — параметрлер, ал эми 4, 6, 10, 20 — чакырууда берилген аргументтер.

Параметрлерге демейки маани берүү

def salam(aty="окуучу"):
    print("Салам,", aty)

salam("Айжан")
salam()

Натыйжасы:

Салам, Айжан
Салам, окуучу

Аргумент берилбесе, функция демейки маанини колдонот.

3. Локалдык жана глобалдык өзгөрмөлөр

Локалдык өзгөрмө функциянын ичинде түзүлөт жана негизинен ошол функциянын ичинде гана жеткиликтүү болот.

def esepte():
    san = 15
    print(san)

esepte()

Бул мисалда san — локалдык өзгөрмө.

Глобалдык өзгөрмө функциялардын сыртында аныкталат жана программадагы тиешелүү аймактардан окула алат.

maalymat = "Информатика"

def korsot():
    print(maalymat)

korsot()

Функция глобалдык өзгөрмөнүн маанисин окуй алат.

global ачкыч сөзү

Функциянын ичинде глобалдык өзгөрмөнүн маанисин өзгөртүү керек болсо, global ачкыч сөзү колдонулат.

san = 5

def ozgort():
    global san
    san = 12

ozgort()
print(san)

Натыйжасы: 12.

Эскертүү: мүмкүн болушунча функцияга керектүү маанилерди параметр аркылуу берип, натыйжасын return менен кайтарган жакшы. Глобалдык өзгөрмөлөрдү көп колдонуу программаны түшүнүүнү жана текшерүүнү кыйындатышы мүмкүн.

4. Функциядан маанилерди кайтаруу — return

return оператору функциянын аткарылышын токтотуп, чакырган жерге натыйжаны кайтарат. Кайтарылган маанини өзгөрмөгө сактап, башка эсептөөлөрдө колдонсо болот.

def kvadrat(x):
    return x * x

natija = kvadrat(5)
print(natija)

Натыйжасы: 25.

Эми функцияны print менен салыштыралы:

def birinchi():
    print(8)

def ekinchi():
    return 8

a = birinchi()
b = ekinchi()

print("a =", a)
print("b =", b)

Натыйжасы:

8
a = None
b = 8

print маанини экранга чыгарат, ал эми return маанини функция чакырылган жерге кайтарат. Эгер функцияда return жок болсо, Python автоматтык түрдө None кайтарат.

5. lambda-функциялар

lambda-функция — аты жок, бир туюнтмадан турган кыска функция. Ал жөнөкөй аракеттерди кыска жазуу үчүн колдонулат.

kvadrat = lambda x: x * x

print(kvadrat(6))

Натыйжасы: 36.

Кадимки функциянын ушундай түрү:

def kvadrat(x):
    return x * x

Lambda түрү:

kvadrat = lambda x: x * x

Эки аргументтүү lambda

koshuu = lambda a, b: a + b

print(koshuu(7, 3))

Натыйжасы: 10.

Эсиңде болсун: lambda бир гана туюнтманы камтыйт. Бир нече командадан турган татаал функция үчүн def колдонуу ыңгайлуу.

6. Практикалык иштер

Тапшырмаларды Python чөйрөсүндө аткаргыла. Ар бир программа үчүн киргизилген маанилерди жана алынган натыйжаны текшергиле.

  1. Жеңил: атын аргумент катары кабыл алып, «Салам, [аты]!» деп чыгаруучу функция түзгүлө.
  2. Орто: эки санды кабыл алып, алардын көбөйтүндүсүн return аркылуу кайтарган функция жазгыла.
  3. Орто: санды кабыл алып, анын жуп же так экенин кайтарган функция түзгүлө.
  4. Татаал: үч сандын эң чоңун кайтарган функция түзгүлө. Андан кийин ошол функцияны lambda эмес, def менен жазгыла.
  5. Кошумча: эки санды кошкон lambda-функция түзүп, аны үч башка аргумент жубу менен чакыргыла.
Кеңеш: жуп санды текшерүүдө n % 2 == 0 шартын колдонгула. Функциядан жыйынтык кайтаруу үчүн return операторун унутпагыла.

8. Үй тапшырма

1ден берилген N санына чейинки сандардын суммасын эсептеген функция түзгүлө. Функция N санын аргумент катары кабыл алып, сумманы return менен кайтарсын. Андан соң эки санды салыштырып, чоңун кайтарган lambda-функция жазгыла.
