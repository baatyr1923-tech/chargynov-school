3-ай. 6-сабак. Квадраттык теңдемелер

🎯 Сабактын максаты

Квадраттык теңдемени таануу, дискриминантты эсептөө жана теңдеменин тамырларын табуу.

1. Квадраттык теңдеме деген эмне?

Белгисиздин эң чоң даражасы 2 болгон теңдеме квадраттык теңдеме деп аталат.

ax² + bx + c = 0

Бул жерде:

  • a — x² тин коэффициенти, a ≠ 0;
  • b — x тин коэффициенти;
  • c — бош мүчө.
Мисал: 2x² + 5x − 3 = 0 теңдемесинде a = 2, b = 5, c = −3.

2. Дискриминант

Квадраттык теңдеменин тамырларынын санын аныктоо үчүн дискриминант эсептелет.

D = b² − 4ac
  • D > 0 болсо — эки ар башка тамыр бар.
  • D = 0 болсо — бир кош тамыр бар.
  • D < 0 болсо — чыныгы тамыры жок.

3. Тамырларды табуу формуласы

x₁ = (−b + √D) / 2a
x₂ = (−b − √D) / 2a

Бул формулалар D ≥ 0 болгондо колдонулат.

4. Чыгарылган мисалдар

Мисал 1: x² − 5x + 6 = 0

a = 1, b = −5, c = 6
D = (−5)² − 4 · 1 · 6 = 25 − 24 = 1
x₁ = (5 + 1) / 2 = 3
x₂ = (5 − 1) / 2 = 2
Жообу: x₁ = 3, x₂ = 2.
Мисал 2: x² − 4x + 4 = 0

D = (−4)² − 4 · 1 · 4 = 16 − 16 = 0
x = 4 / 2 = 2
Жообу: x = 2.
Мисал 3: x² + x + 1 = 0

D = 1² − 4 · 1 · 1 = 1 − 4 = −3
D < 0 болгондуктан, чыныгы тамыры жок.
Мисал 4: x² − 9 = 0

x² = 9
x = ±3
Жообу: x₁ = 3, x₂ = −3.

5. Өз алдынча иштөө

Төмөнкү теңдемелерди дискриминант аркылуу чыгаргыла.

  1. x² − 7x + 12 = 0
  2. x² − 6x + 9 = 0
  3. x² + 2x + 5 = 0
  4. 2x² − 8x + 6 = 0
  5. x² − 16 = 0

6. Текшерүү тести

10 суроого жооп берип, «Жоопторду текшерүү» баскычын басыңыз.

1. Квадраттык теңдеменин жалпы түрү кайсы?
2. Дискриминанттын формуласы кайсы?
3. D > 0 болсо, теңдеменин канча тамыры болот?
4. x² − 5x + 6 = 0 теңдемесинде a канча?
5. x² − 5x + 6 = 0 теңдемесинин дискриминанты канча?
6. x² − 5x + 6 = 0 теңдемесинин тамырлары кайсы?
7. D = 0 болсо, канча тамыр болот?
8. x² − 9 = 0 теңдемесинин тамырлары кайсы?
9. x² + 1 = 0 теңдемесинин чыныгы тамыры барбы?
10. x² − 4x + 4 = 0 теңдемесинин тамыры канча?

📌 Сабактын жыйынтыгы

Бул сабакта квадраттык теңдеменин жалпы түрүн, дискриминантты жана тамырларды табуу формулаларын үйрөндүк.
