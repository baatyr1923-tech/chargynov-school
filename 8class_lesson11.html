Сабактын максаты

Окуучулар маалыматтар базасын башкаруу системаларынын милдетин түшүнүшөт, MySQL жана Microsoft Access программаларынын негизги өзгөчөлүктөрүн салыштырып, маалыматтар базасынын таблица, талаа жана жазуу түшүнүктөрүн өздөштүрүшөт.

Күтүлүүчү натыйжалар

  • МББС түшүнүгүн жана анын милдеттерин түшүндүрөт.
  • MySQL менен Microsoft Accessтин айырмасын айтат.
  • Таблица, талаа жана жазуу түшүнүктөрүн ажыратат.
  • Форма, сурам жана отчеттун кызматын түшүндүрөт.

1. МББС деген эмне?

Маалыматтар базасын башкаруу системасы (МББС) — маалыматтарды түзүүгө, сактоого, издөөгө, өзгөртүүгө жана өчүрүүгө жардам берген программа.

Мисалы, мектептин окуучуларынын аты-жөнүн, классын, туулган жылын жана бааларын бир системада сактоого болот.

Негизги түшүнүктөр: таблица — маалымат сакталган торчо; талаа — таблицанын мамычасы; жазуу — таблицанын бир сабы.

2. MySQL программасы

MySQL — реляциялык маалыматтар базасын башкаруу системасы. Ал маалыматтарды таблицаларда сактайт жана SQL тили аркылуу маалыматтарды башкарууга мүмкүндүк берет. Көп учурда веб-сайттарда, серверлерде жана маалымат көп болгон системаларда колдонулат.

CREATE DATABASE Mektep;
USE Mektep;

CREATE TABLE Okuuchular (
    id INT PRIMARY KEY,
    aty VARCHAR(50),
    klass VARCHAR(10)
);

Бул мисалда Mektep аттуу база жана Okuuchular аттуу таблица түзүлөт.

3. Microsoft Access программасы

Microsoft Access — маалыматтар базасы менен иштөөчү программа. Ал таблицаларды, формаларды, сурамдарды жана отчетторду түзүүгө жардам берет.

  • Table (Таблица): маалыматтарды талаалар жана жазуулар түрүндө сактайт.
  • Form (Форма): маалыматтарды ыңгайлуу киргизүүгө жана көрүүгө жардам берет.
  • Query (Сурам): керектүү маалыматтарды шарт боюнча тандап алат.
  • Report (Отчет): маалыматтарды иреттүү көрсөтүп, басып чыгарууга даярдайт.
