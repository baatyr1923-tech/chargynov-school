13-сабак: SQL тилинин негиздери

8-класс | Информатика

Сабактын максаты

Окуучулар SQL тилинин негизги түшүнүктөрүн үйрөнүшөт. Маалыматтар базасынан маалыматтарды тандоо, кошуу, өзгөртүү жана өчүрүү командалары менен таанышышат.

1. SQL деген эмне?

SQL (Structured Query Language) — маалыматтар базасы менен иштөө үчүн колдонулган структураланган сурамдар тили.

SQL аркылуу маалыматтар базасын түзүүгө, маалыматтарды сактоого, издөөгө, өзгөртүүгө жана өчүрүүгө болот.

Мисал: Мектептин окуучулары жөнүндө маалыматтарды сактаган базадан белгилүү бир окуучуну издөө үчүн SQL колдонулат.

2. SQL тилинин негизги командалары

КомандаАткарган кызматы
SELECTМаалыматтарды тандоо
INSERTЖаңы маалымат кошуу
UPDATEМаалыматты өзгөртүү
DELETEМаалыматты өчүрүү
CREATE TABLEЖаңы таблица түзүү

3. SELECT — маалыматтарды тандоо

SELECT командасы таблицадан керектүү маалыматтарды алуу үчүн колдонулат.

SELECT * FROM Okuuchular;

Бул команда Okuuchular таблицасындагы бардык маалыматтарды көрсөтөт.

Белгилүү бир талааны тандоо:

SELECT Аты FROM Okuuchular;

4. INSERT — жаңы маалымат кошуу

INSERT командасы таблицага жаңы жазуу кошот.

INSERT INTO Okuuchular (Аты, Классы)
VALUES ('Асан', 8);

Бул команда таблицага Асан аттуу 8-класстын окуучусун кошот.

5. UPDATE — маалыматты өзгөртүү

UPDATE командасы таблицадагы маалыматты өзгөртүү үчүн колдонулат.

UPDATE Okuuchular
SET Классы = 9
WHERE Аты = 'Асан';

Бул команда Асан аттуу окуучунун классын 9-класска өзгөртөт.

Эскертүү: UPDATE командасында WHERE шартын туура колдонуу керек. Болбосо таблицадагы бардык жазуулар өзгөрүп калышы мүмкүн.

6. DELETE — маалыматты өчүрүү

DELETE командасы таблицадагы керексиз жазууларды өчүрөт.

DELETE FROM Okuuchular
WHERE Аты = 'Асан';

Бул команда Асан аттуу окуучунун жазуусун өчүрөт.

Эскертүү: WHERE шартын көрсөтпөсөңүз, таблицадагы бардык жазуулар өчүп калышы мүмкүн.

7. Практикалык тапшырмалар

Төмөнкү тапшырмаларды дептерге же компьютерде аткаргыла.

  1. Okuuchular аттуу таблицадагы бардык маалыматтарды чыгарган SQL командасын жазгыла.
  2. Таблицага Айжан аттуу 8-класстын окуучусун кошкон команданы түзгүлө.
  3. Айжан аттуу окуучунун классын 9-класска өзгөрткүлө.
  4. Асан аттуу окуучунун жазуусун өчүргөн команданы жазгыла.
  5. SQL тилинин колдонулушуна үч мисал келтиргиле.

Жыйынтык

SQL — маалыматтар базасы менен иштөөнүн маанилүү куралы. Анын жардамы менен маалыматтарды тандоого, кошууга, өзгөртүүгө жана өчүрүүгө болот.

Үй тапшырма: SQL тилинин SELECT, INSERT, UPDATE жана DELETE командаларына бирден мисал жазып келгиле.
