Санак системаларынын ортосунда конвертация

🎯 Сабактын максаты

  • Бир санак системасынан экинчисине өтүүнү үйрөнүү.
  • Экилик санды ондук системага которуу.
  • Ондук санды экилик системага которуу.
  • Сегиздик жана он алтылык системалар менен иштөө.

📚 1. Конвертация деген эмне?

Конвертация — санды бир санак системасынан башка санак системасына которуу.

Мисалы:

1010₂ = 10₁₀

Бул жерде 1010 — экилик системадагы сан, ал эми 10 — ондук системадагы сан.

🔢 2. Экиликтен ондукка өткөрүү

Экилик сандын ар бир цифрасы 2нин тиешелүү даражасына көбөйтүлөт.

Мисал: 1011₂ → ?₁₀

1011₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰
= 1×8 + 0×4 + 1×2 + 1×1
= 8 + 0 + 2 + 1
= 11₁₀

🔄 3. Ондуктан экиликке өткөрүү

Ондук санды 2ге бөлөбүз жана калдыктарды жазып барабыз. Акырында калдыктарды төмөндөн жогору карай окуйбуз.

Мисал: 13₁₀ → ?₂

13 ÷ 2 = 6, калдык 1
6 ÷ 2 = 3, калдык 0
3 ÷ 2 = 1, калдык 1
1 ÷ 2 = 0, калдык 1

Калдыктарды төмөндөн жогору окуйбуз:
1101₂

Демек:
13₁₀ = 1101₂

🔢 4. Ондуктан сегиздикке өткөрүү

Мисал: 25₁₀ → ?₈

25 ÷ 8 = 3, калдык 1
3 ÷ 8 = 0, калдык 3

Калдыктарды төмөндөн жогору окуйбуз:
31₈

Демек: 25₁₀ = 31₈

🔷 5. Ондуктан он алтылыкка өткөрүү

Мисал: 26₁₀ → ?₁₆

26 ÷ 16 = 1, калдык 10
Он алтылык системада 10 = A.

Демек: 26₁₀ = 1A₁₆

💡 Эсиңизде болсун!

2нин даражалары боюнча эсептейбиз.
Ондуктан экиликке:
2ге бөлүп, калдыктарды тескери тартипте окуйбуз.
Ондуктан сегиздикке:
8ге бөлүп, калдыктарды тескери тартипте окуйбуз.
Ондуктан он алтылыкка:
16га бөлүп, калдыктарды тескери тартипте окуйбуз.
