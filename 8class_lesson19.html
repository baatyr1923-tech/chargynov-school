Сабактын максаты

Окуучулар массив түшүнүгүн өздөштүрүшөт. Python тилиндеги list тизмеси аркылуу бир нече маанини сактоону, элементтерди киргизип-чыгарууну, иргөөнү, тизмени толтуруучу генераторлорду жана үзүмдөрдү колдонууну үйрөнүшөт.

Күтүлүүчү натыйжалар

  • Массивдин жана Python тизмесинин маанисин түшүндүрөт.
  • Тизменин элементтерине индекси аркылуу кайрылат.
  • Тизмени киргизет жана экранга чыгарат.
  • Элементтерди өсүү жана кемүү тартибинде иреттейт.
  • Тизмени толтуруучу генераторлорду колдонот.
  • Үзүмдөр менен тизмеден бөлүк алат.

1. Массив деген эмне?

Массив — бир аталыш менен бир нече маанини иреттүү түрдө сактоого мүмкүндүк берген маалымат түзүмү. Ар бир элементтин өзүнүн орду (индекси) болот.

Python тилинде мектептик тапшырмаларда массивге окшош түзүм катары көбүнчө тизме (list) колдонулат. Тизме бир нече маанини бир өзгөрмөдө сактайт жана анын өлчөмү өзгөрө алат.

baalar = [5, 4, 5, 3, 4]
atylar = ["Айжан", "Бек", "Нур"]

print(baalar)
print(atylar)

Натыйжасы:

[5, 4, 5, 3, 4]
['Айжан', 'Бек', 'Нур']
Эсиңде болсун: Python тизмесинин элементтери ар кандай типте болушу мүмкүн, бирок бир типтеги маалыматтарды чогуу сактоо жана иштетүү көп учурда ыңгайлуу.

2. Тизменин элементтери жана индекстер

Тизменин ар бир элементинин индекси бар. Python тилинде индекстер 0дөн башталат.

san = [12, 25, 8, 40, 17]

print(san[0])  # биринчи элемент
print(san[2])  # үчүнчү элемент
print(san[-1]) # акыркы элемент

Натыйжасы:

12
8
17
Элемент122584017
Индекс01234

Тизменин элементин өзгөртүүгө болот:

san = [12, 25, 8]
san[1] = 30
print(san)

Натыйжасы: [12, 30, 8].

Элементтердин санын билүү үчүн len() функциясы колдонулат:

print(len(san))

Натыйжасы: 3.

3. Массивдерди (тизмелерди) киргизүү жана чыгаруу

Даяр маанилерди тизмеге жазуу

san = [4, 7, 2, 9]
print("Тизме:", san)

for element in san:
    print(element)

Колдонуучудан бир сап менен сандарды киргизүү

split() сапты боштук боюнча бөлөт, ал эми map(int, ...) алынган маанилерди бүтүн сандарга айландырат.

san = list(map(int, input(
    "Сандарды боштук менен киргизиңиз: "
).split()))

print("Киргизилген тизме:", san)

Мисалы, колдонуучу 5 8 2 10 деп киргизсе, тизме [5, 8, 2, 10] болот.

Элементтерди цикл менен киргизүү

n = int(input("Элементтердин саны: "))
san = []

for i in range(n):
    x = int(input("Сан киргизиңиз: "))
    san.append(x)

print("Тизме:", san)

append() жаңы элементти тизменин аягына кошот.

4. Элементтерди иргөө (сорттоо)

Иргөө — тизмедеги элементтерди белгилүү бир тартипке келтирүү. Көбүнчө сандарды өсүү же кемүү тартибинде жайгаштырабыз.

sort() методу

sort() тизмени ордунда өзгөртөт.

san = [7, 2, 9, 1, 5]

san.sort()
print(san)

Натыйжасы: [1, 2, 5, 7, 9].

Кемүү тартибинде иргөө:

san.sort(reverse=True)
print(san)

Натыйжасы: [9, 7, 5, 2, 1].

sorted() функциясы

sorted() баштапкы тизмени өзгөртпөстөн, иреттелген жаңы тизме кайтарат.

san = [7, 2, 9, 1, 5]
irgelgen = sorted(san)

print("Баштапкы:", san)
print("Иреттелген:", irgelgen)

Натыйжасы:

Баштапкы: [7, 2, 9, 1, 5]
Иреттелген: [1, 2, 5, 7, 9]
Айырмасын эстеп кал: sort() баштапкы тизмени өзгөртөт; sorted() жаңы иреттелген тизме берет.

5. Тизмени толтуруучу генераторлор (list comprehension)

Тизмени толтуруучу генератор — белгилүү бир эрежеге ылайык жаңы тизме түзүүнүн кыска жолу. Ал for циклин бир сапта колдонууга мүмкүнчүлүк берет.

kvadrat = [x * x for x in range(1, 6)]
print(kvadrat)

Натыйжасы: [1, 4, 9, 16, 25].

Шарт менен тизме түзүү

jup_sandar = [x for x in range(1, 11)
              if x % 2 == 0]

print(jup_sandar)

Натыйжасы: [2, 4, 6, 8, 10].

Жалпы жазылышы:

[туюнтма for элемент in тизмек if шарт]

if шарты милдеттүү эмес. Шартсыз жазганда тизмектеги бардык элементтер иштетилет.

6. Үзүмдөр (slicing)

Үзүм — тизмеден белгилүү бир бөлүгүн алуу. Ал үчүн төрт бурчтуу кашаанын ичинде башталыш, аяктоо жана кадам көрсөтүлөт.

san = [10, 20, 30, 40, 50, 60]

print(san[1:4])
print(san[:3])
print(san[3:])
print(san[::2])

Натыйжасы:

[20, 30, 40]
[10, 20, 30]
[40, 50, 60]
[10, 30, 50]
ЖазылышыТүшүндүрмө
san[1:4]1-индекстен 4-индекске чейин, 4 кирбейт
san[:3]Башынан 3-индекске чейин
san[3:]3-индекстен аягына чейин
san[::2]Ар бир экинчи элемент
san[::-1]Тескери тартипте көчүрмө
Маанилүү: үзүмдө аяктоо индекси алынган бөлүккө кирбейт. Мисалы, san[1:4] 1, 2, 3 индекстеги элементтерди алат.

7. Практикалык иштер

Тапшырмаларды Python чөйрөсүндө аткаргыла. Натыйжаларын текшерип, коддогу өзгөрмөлөрдүн маанилерин түшүндүргүлө.

  1. Жеңил: беш сандан турган тизме түзүп, биринчи, үчүнчү жана акыркы элементтерин экранга чыгаргыла.
  2. Орто: колдонуучудан бир сап менен 5 сан киргизип, алардын суммасын эсептегиле.
  3. Орто: берилген сандар тизмесин өсүү жана кемүү тартибинде иргегиле. sort() менен sorted() айырмасын көрсөтгүлө.
  4. Орто: list comprehension колдонуп, 1ден 20га чейинки так сандардан жаңы тизме түзгүлө.
  5. Татаал: берилген тизмеден экинчи элементтен баштап төртүнчү элементке чейинки үзүмдү чыгаргыла. Андан соң тизмени тескери тартипте чыгаргыла.
