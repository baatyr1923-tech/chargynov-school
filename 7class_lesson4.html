№35–Жумабек Чаргынов атындагы орто билим берүү мектеби

💻 7-класс — 4-сабак

Тема: Тексттик маалыматты коддоо

📚 Сабактын максаты

Окуучулар тексттик маалыматты компьютерде коддоо түшүнүгүн билишет, тексттин стандарттык коддоолору менен таанышат жана ASCII коддук таблицасын колдонуп символдордун коддорун аныктай алышат.

💡 1. Тексттик маалыматты коддоо деген эмне?

Компьютер текстти түздөн-түз тамгалар түрүндө эмес, атайын сандык коддор аркылуу сактайт жана иштетет.

Ар бир тамга, цифра, боштук же атайын белги компьютердин эсинде белгилүү бир код менен көрсөтүлөт.

Мисал:

Адам компьютерге A тамгасын киргизсе, компьютер аны белгилүү бир сандык код катары сактай алат.

ASCII кодунда: A = 65

Эсте сакта!

Тексттик маалыматты коддоо — символдорду компьютер түшүнө турган сандык коддорго айландыруу процесси.

🔤 2. Тексттин стандарттык коддоолору

Ар кандай тилдердеги символдорду компьютерде көрсөтүү үчүн атайын коддоо стандарттары колдонулат.

ASCII

ASCII — англис алфавитиндеги тамгаларды, цифраларды жана айрым атайын белгилерди коддоо үчүн колдонулган стандарт.

Unicode

Unicode — дүйнөнүн көптөгөн тилдериндеги символдорду коддоого мүмкүндүк берген заманбап стандарт.

Кыргыз, орус, англис жана башка тилдердин символдорун көрсөтүүгө мүмкүндүк берет.

Маанилүү:

ASCII негизинен англис тилинин символдорун коддоого багытталган. Ал эми Unicode көптөгөн тилдердин символдорун камтыйт.

📋 3. Коддук таблица

Коддук таблица — символдор менен алардын сандык коддорунун ортосундагы дал келүүнү көрсөтүүчү таблица.

Мисалы, ASCII таблицасында:

Символ ASCII коду Он алтылык код
A 65 41
B 66 42
C 67 43
a 97 61
b 98 62
0 48 30
1 49 31
2 50 32
Space 32 20

💻 4. ASCII таблицасы

ASCII сөзү англис тилиндеги American Standard Code for Information Interchange деген аталыштан алынган.

ASCII стандартында символдор сандык маанилер менен берилет. Классикалык ASCII таблицасы 0дөн 127ге чейин болгон коддорду камтыйт.

Мисалдар:

A → 65

B → 66

C → 67

a → 97

b → 98

0 → 48

Көңүл бур!

Чоң жана кичине тамгалардын коддору ар башка. Мисалы:

A = 65, бирок a = 97.

🧮 5. Мисалдарды чыгаралы

Мисал 1

A тамгасынын ASCII коду канча?

Жооп: 65

Мисал 2

ABC сөзүндөгү символдордун ASCII коддорун тапкыла.

A = 65
B = 66
C = 67

Демек: ABC → 65, 66, 67

Мисал 3

12 символдорунун ASCII коддорун тапкыла.

1 = 49
2 = 50

Демек: 12 → 49, 50

🛠️ 6. Практикалык иш

Төмөнкү символдордун ASCII коддорун таблицадан тапкыла:

1. A

2. C

3. a

4. b

5. 0

6. 5

7. боштук (Space)

Кошумча тапшырма:

HELLO сөзүндөгү ар бир тамганын ASCII кодун жазгыла.

📝 7. Тест

1. Тексттик маалымат компьютерде кандай түрдө сакталат?

A) Сандык коддор түрүндө
Б) Сүрөт түрүндө гана
В) Үн түрүндө гана
Г) Кагаз түрүндө

Жооп: A

2. ASCII деген эмне?

A) Сүрөт редактору
Б) Текстти коддоо стандарты
В) Оюн программасы
Г) Антивирус

Жооп: Б

3. ASCII стандартындагы A тамгасынын коду канча?

A) 32
Б) 48
В) 65
Г) 97

Жооп: В

4. ASCII стандартындагы a тамгасынын коду канча?

A) 65
Б) 66
В) 96
Г) 97

Жооп: Г

5. ASCII стандартындагы 0 цифрасынын коду канча?

A) 30
Б) 32
В) 48
Г) 65

Жооп: В

6. Коддук таблица эмне үчүн колдонулат?

A) Символ менен анын кодунун дал келүүсүн табуу үчүн
Б) Сүрөт тартуу үчүн
В) Музыка угуу үчүн
Г) Видео көрүү үчүн

Жооп: A

7. ASCIIнин классикалык версиясы канча кодду камтыйт?

A) 64
Б) 100
В) 128
Г) 256

Жооп: В

8. Unicode эмнеси менен айырмаланат?

A) Көптөгөн тилдердин символдорун колдойт
Б) Бир гана цифраларды колдойт
В) Сүрөттөрдү гана сактайт
Г) Интернетсиз гана иштейт

Жооп: A

9. ASCII боюнча B тамгасынын коду канча?

A) 65
Б) 66
В) 67
Г) 98

Жооп: Б

10. ASCII боюнча Space символунун коду канча?

A) 0
Б) 10
В) 32
Г) 64

Жооп: В

💡 Сабактын негизги жыйынтыгы

Тексттик маалымат компьютерде сандык коддор аркылуу көрсөтүлөт.

ASCII — символдорду коддоонун стандарттарынын бири.

Коддук таблица символ менен анын сандык кодунун ортосундагы байланышты көрсөтөт.

Классикалык ASCII таблицасында 128 код бар. Ал эми Unicode көптөгөн тилдердин символдорун колдоого ылайыкталган.

🏠 Үй тапшырмасы

1. ASCII деген эмне экенин жазып келүү.

2. A, B, C, a, b, c тамгаларынын ASCII коддорун жаттоо.

3. HELLO сөзүндөгү ар бир тамганын ASCII кодун жазуу.
