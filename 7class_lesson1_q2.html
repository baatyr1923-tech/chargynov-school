  • Windows, macOS жана Linux системаларын айырмалоо.

  • Файлдарды түзүү, атын өзгөртүү, жылдыруу жана жок кылууну өздөштүрүү.

1. Операциялык система деген эмне?

Операциялык система (ОС) — компьютердин түзүлүштөрүн жана программаларын башкаруучу негизги программалык камсыздоо.

Операциялык система компьютер менен колдонуучунун ортосунда байланыш түзөт.

Операциялык системалардын мисалдары:

Windows — Microsoft компаниясы иштеп чыккан операциялык система. Компьютерлерде кеңири колдонулат.
macOS — Apple компаниясынын MacBook жана iMac компьютерлери үчүн операциялык системасы.
Linux — ачык коддуу операциялык система. Серверлерде жана компьютерлерде колдонулат.

2. Файл деген эмне?

Файл — компьютерде сакталган маалыматтын белгилүү бир аталышы бар бөлүгү.

Файлдарда текст, сүрөт, музыка, видео жана башка маалыматтар сакталат.

Файлдардын түрлөрү:

  • Тексттик файл — .txt, .docx
  • Сүрөт — .jpg, .png
  • Музыка — .mp3
  • Видео — .mp4
  • Презентация — .pptx

3. Папка деген эмне?

Папка — файлдарды жана башка папкаларды иреттеп сактоо үчүн колдонулуучу жай.

Мисалы, «Информатика» деген папканын ичинде сабактардын документтери жана сүрөттөрү болушу мүмкүн.

4. Файлдык система

Файлдык система — маалыматтарды сактоо түзүлүшүндө файлдарды жана папкаларды уюштуруу, жайгаштыруу жана табуу эрежелеринин жыйындысы.

Мисалдар: NTFS, FAT32, exFAT, APFS, ext4.

5. Файлдар менен иштөө

  • Түзүү: жаңы файл же папка ачуу.
  • Атын өзгөртүү: файлдын атын алмаштыруу.
  • Жылдыруу: файлды башка папкага көчүрүп жайгаштыруу.
  • Жок кылуу: керексиз файлды өчүрүү.
  • Көчүрүү: файлдын дагы бир нускасын түзүү.
