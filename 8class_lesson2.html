Санак системаларында сандарды көрсөтүү

Сандардын ар түрдүү санак системаларында жазылышын үйрөнөбүз.

🎯 Сабактын максаты

  • Сандын разряддык түзүлүшүн түшүнүү;
  • Санак системасынын негизин аныктоо;
  • Сандарды ар түрдүү санак системаларында туура жазуу;
  • Экилик, сегиздик жана он алтылык сандарды окуу.

📚 1. Санак системасында сан кандай көрсөтүлөт?

Ар бир сан белгилүү бир санак системасынын эрежеси боюнча жазылат.

Санак системасынын негизин анын төмөнкү индекси көрсөтөт.

2510 — ондук санак системасы

10112 — экилик санак системасы

178 — сегиздик санак системасы

2A16 — он алтылык санак системасы

🔢 2. Разряд деген эмне?

Сандын ар бир цифрасы белгилүү бир орунда турат. Бул орун разряд деп аталат.

Мисалы, 345 санын карайлы:

345 = 3×100 + 4×10 + 5×1

345 = 3×102 + 4×101 + 5×100

Демек, цифранын мааниси анын турган ордуна жараша өзгөрөт.

💻 3. Экилик системада сандар

Экилик санак системасында болгону 0 жана 1 цифралары колдонулат.

10112

= 1×23 + 0×22 + 1×21 + 1×20

= 8 + 0 + 2 + 1

= 1110

🔢 4. Сегиздик системада сандар

Сегиздик санак системасынын негизи 8. Анда 0дөн 7ге чейинки цифралар колдонулат.

178

= 1×81 + 7×80

= 8 + 7

= 1510

🔠 5. Он алтылык системада сандар

Он алтылык системанын негизи 16. 0–9 цифраларынан тышкары A–F тамгалары колдонулат.

Белги Мааниси
A 10
B 11
C 12
D 13
E 14
F 15
2A16

= 2×16 + 10

= 4210

📊 6. Салыштыруу

Система Негизи Колдонулган белгилер
Экилик 2 0, 1
Сегиздик 8 0–7
Ондук 10 0–9
Он алтылык 16 0–9, A–F

✏️ 7. Өз алдынча иштөө

1-мисал: 10102 санын ондук системага өткөрүңүз.

10102 = 1×8 + 0×4 + 1×2 + 0×1

= 8 + 2

= 1010

2-мисал: 11012 санын ондук системага өткөрүңүз.

11012 = 1×8 + 1×4 + 0×2 + 1×1

= 8 + 4 + 1

= 1310

3-мисал: 258 санын ондук системага өткөрүңүз.

258 = 2×8 + 5

= 2110

🎯 Эсиңизде болсун!

  • Экилик системанын негизи — 2;
  • Сегиздик системанын негизи — 8;
  • Ондук системанын негизи — 10;
  • Он алтылык системанын негизи — 16;
  • Он алтылык системада A = 10, B = 11, C = 12, D = 13, E = 14, F = 15.
