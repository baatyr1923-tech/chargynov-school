Сабактын максаты

Окуучулар циклдик алгоритмдин маанисин түшүнүшөт, Python тилиндеги while жана for циклдерин колдонушат, кайталоо аркылуу эсептерди чыгарып, жөнөкөй программаларды түзүшөт.

Күтүлүүчү натыйжалар

  • Цикл жана циклдик алгоритм түшүнүктөрүн түшүндүрөт.
  • while циклинин шарт менен иштешин билет.
  • for циклин жана range() функциясын колдонот.
  • Циклдердин жардамы менен эсептөөчү программа түзөт.

1. Циклдик алгоритм деген эмне?

Циклдик алгоритм — белгилүү бир аракеттерди бир нече жолу кайталап аткаруучу алгоритм. Мисалы, 1ден 100гө чейинки сандарды чыгаруу, сандардын суммасын эсептөө же көбөйтүү таблицасын түзүүдө цикл колдонулат.

Эсиңде болсун: бир эле команданы кайра-кайра жазуунун ордуна, аны циклдин ичине жайгаштырабыз. Ошондо программа кыска жана түшүнүктүү болот.

2. while цикли

while цикли берилген шарт True (туура) болуп турганда командаларды кайталап аткарат. Шарт ар бир кайталоонун алдында текшерилет.

while шарт:
    аткарылуучу_команда

Мисал 1. 1ден 5ке чейинки сандарды чыгаруу

i = 1

while i <= 5:
    print(i)
    i += 1

Натыйжасы:

1
2
3
4
5

Түшүндүрмө:

  1. i = 1 — баштапкы маани берилди.
  2. i <= 5 — циклдин шарты текшерилет.
  3. print(i) — учурдагы сан экранга чыгарылат.
  4. i += 1 — өзгөрмөнүн мааниси 1ге көбөйөт.
Эскертүү: while циклинде шартка таасир этүүчү өзгөрмө өзгөртүлбөсө, цикл чексиз кайталанып калышы мүмкүн.

3. for цикли

for цикли белгилүү бир тизмектин же диапазондун элементтери боюнча кайталоо жүргүзөт. Кайталоолордун саны алдын ала белгилүү болгондо колдонуу ыңгайлуу.

for өзгөрмө in тизмек:
    аткарылуучу_команда

Мисал 2. 1ден 5ке чейинки сандарды чыгаруу

for i in range(1, 6):
    print(i)

5. Практикалык мисалдар

Мисал 3. 1ден 10го чейинки сандардын суммасы

s = 0

for i in range(1, 11):
    s += i

print("Суммасы:", s)

Натыйжасы: Суммасы: 55.

Мисал 4. Киргизилген сан үчүн көбөйтүү таблицасы

n = int(input("Санды киргизиңиз: "))

for i in range(1, 11):
    print(n, "*", i, "=", n * i)

Мисалы, 3 саны киргизилсе, программа 3 × 1ден 3 × 10го чейинки көбөйтүү таблицасын чыгарат.

Мисал 5. 10дон 1ге чейин тескери саноо

i = 10

while i >= 1:
    print(i)
    i -= 1

6. Практикалык иштер

Тапшырмаларды Python чөйрөсүндө аткаргыла. Ар бир программа иштегенден кийин натыйжасын текшергиле.

  1. Жеңил: for циклин колдонуп 1ден 20га чейинки сандарды чыгаргыла.
  2. Орто: while циклин колдонуп 1ден 50гө чейинки жуп сандарды чыгаргыла.
  3. Орто: 1ден 100гө чейинки 3кө бөлүнгөн сандардын суммасын эсептегиле.
  4. Татаал: колдонуучу киргизген N санына чейин 1ден баштап бардык сандарды чыгарган программа түзгүлө.
Кеңеш: жуп санды текшерүү үчүн i % 2 == 0, ал эми 3кө бөлүнүүнү текшерүү үчүн i % 3 == 0 шартын колдонсо болот.
