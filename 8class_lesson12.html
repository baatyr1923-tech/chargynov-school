12-сабак: Маалыматтар базасында маалыматтар менен иштөө операциялары

8-класс | Информатика

Сабактын максаты

Окуучулар маалыматтар базасында маалыматтарды кошуу, өзгөртүү, өчүрүү, издөө жана иргөө операцияларын үйрөнүшөт.

1. Маалыматтар базасын башкаруу системасы деген эмне?

Маалыматтар базасын башкаруу системасы (МББС) — маалыматтарды түзүүгө, сактоого, издөөгө, өзгөртүүгө жана өчүрүүгө жардам берген программа.

Мисалы, мектептин окуучулары жөнүндө маалыматтарды сактоо үчүн маалыматтар базасын колдонсо болот.

Мисал: Окуучунун аты-жөнү, классы, туулган жылы жана баалары маалыматтар базасында сакталат.

2. Маалыматтарды кошуу (INSERT)

INSERT командасы таблицага жаңы маалымат кошуу үчүн колдонулат.

INSERT INTO Okuuchular (Аты, Классы)
VALUES ('Асан', 8);

Бул мисал Okuuchular таблицасына Асан аттуу 8-класстын окуучусун кошот.

3. Маалыматтарды издөө (SELECT)

SELECT командасы таблицадагы керектүү маалыматтарды издөө жана тандоо үчүн колдонулат.

SELECT * FROM Okuuchular;
SELECT Аты FROM Okuuchular;

Мисал: Окуучулардын маалыматтарын тандоо үчүн SELECT командасы колдонулат.

SELECT * FROM Okuuchular
ORDER BY Аты ASC;

ORDER BY командасы маалыматтарды иреттейт. ASC — өсүү тартибинде, DESC — кемүү тартибинде.

4. Маалыматтарды өзгөртүү (UPDATE)

UPDATE командасы таблицадагы мурдагы маалыматтарды өзгөртүү үчүн колдонулат.

UPDATE Okuuсhular
SET Классы = 9
WHERE Аты = 'Асан';

Бул команда Асан аттуу окуучунун классын 9-класска өзгөртөт.
