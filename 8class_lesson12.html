12-сабак: Маалыматтар базасында маалыматтар менен иштөө операциялары

8-класс | Информатика

Сабактын максаты

Окуучулар маалыматтар базасында маалыматтарды кошуу, өзгөртүү, өчүрүү, издөө жана иргөө операцияларын үйрөнүшөт.

1. Маалыматтар базасын башкаруу системасы деген эмне?

Маалыматтар базасын башкаруу системасы (МББС) — маалыматтарды түзүүгө, сактоого, издөөгө, өзгөртүүгө жана өчүрүүгө жардам берген программа.

Мисалы, мектептин окуучулары жөнүндө маалыматтарды сактоо үчүн маалыматтар базасын колдонсо болот.

Мисал: Окуучунун аты-жөнү, классы, туулган жылы жана баалары маалыматтар базасында сакталат.

2. MySQL программасы

MySQL — маалыматтарды таблицалар түрүндө сактоого жана башкарууга арналган маалыматтар базасын башкаруу системасы.

MySQL веб-сайттарда, интернет-дүкөндөрдө, мектеп системаларында жана башка маалыматтык системаларда колдонулат.

MySQL менен маалыматтарды сактоого, издөөгө, өзгөртүүгө жана өчүрүүгө болот.

3. Microsoft Access программасы

Microsoft Access — маалыматтар базасын түзүүгө жана башкарууга арналган программа.

Access программасында таблицаларды, формаларды, сурамдарды жана отчетторду түзүүгө болот.

  • Таблица — маалыматтарды сактайт.
  • Форма — маалыматтарды киргизүүгө жардам берет.
  • Сурам — керектүү маалыматтарды издейт.
  • Отчет — маалыматтарды иреттүү көрсөтөт.

4. MySQL жана Microsoft Access айырмачылыгы

  • MySQL көбүнчө веб-сайттарда жана серверлерде колдонулат.
  • Microsoft Access чакан маалыматтар базасын түзүүгө ыңгайлуу.
  • Экөө тең маалыматтарды сактоого жана башкарууга жардам берет.
