Сабактын максаты

Окуучулар сандык жана саптык маалыматтардын типтерин айырмалашат. Маалыматты бир типтен экинчи типке айландырууну жана саптарды форматтап, түшүнүктүү түрдө экранга чыгарууну үйрөнүшөт.

Күтүлүүчү натыйжалар

  • int, float жана str типтерин түшүндүрөт.
  • int(), float(), str() функцияларын туура колдонот.
  • input() функциясы киргизген маанинин сап экенин эске алат.
  • f-string жана format() аркылуу сапты форматтайт.
  • Сандарды белгилүү тактыкта чыгарууну билет.

1. Маалыматтардын типтери

Python тилинде ар бир маанинин өзүнүн тиби бар. Бул сабакта үч негизги типти колдонобуз.

ТипМаанисиМисал
intБүтүн сан12, -5, 0
floatБөлчөк сан3.14, -0.5, 7.0
strСаптык маалымат"Салам", "2026"
a = 25
b = 3.14
c = "Python"

print(type(a))
print(type(b))
print(type(c))

type() функциясы өзгөрмөдөгү маанинин тибин көрсөтөт.

2. input() функциясы жана типти өзгөртүү

input() функциясы клавиатурадан маалымат кабыл алат жана алынган маанини сап (str) түрүндө берет. Эгер сан менен эсептөө керек болсо, аны тиешелүү типке айландыруу зарыл.

Бүтүн санга айландыруу — int()

жаш = int(input("Жашыңызды жазыңыз: "))
кийинки = жаш + 1

print("Кийинки жылы жашыңыз:", кийинки)

Бөлчөк санга айландыруу — float()

баа = float(input("Бааны киргизиңиз: "))
кошумча = баа * 0.1

print("10 пайыз кошумча:", кошумча)

Сапка айландыруу — str()

жыл = 2026
текст = "Жыл: " + str(жыл)

print(текст)
Көп кездешкен ката: input() натыйжасын түз эле сан менен кошууга болбойт. Мисалы, "5" + 2 ката берет. Керектүү учурда int() же float() колдонуңуз.

3. Типтерди өзгөртүүнүн мисалдары

сан_сап = "125"
сан = int(сан_сап)
print(сан + 5)       # 130

бөлчөк_сап = "4.5"
бөлчөк = float(бөлчөк_сап)
print(бөлчөк * 2)    # 9.0

сан = 48
сап = str(сан)
print("Жооп: " + сап)

Типти өзгөртүүдө берилген сап туура сандык жазылышта болушу керек. Мисалы, int("abc") аткарылганда ката чыгат.

4. f-string аркылуу форматтоо

Форматтоо — маалыматты экранга белгилүү бир тартипте, ыңгайлуу көрүнүштө чыгаруу. Python тилинде f-string колдонуу оңой: саптын алдына f тамгасы жазылып, өзгөрмөлөр фигуралык кашаага алынат.

аты = "Айдана"
жашы = 14
print(f"Менин атым {аты}, жашым {жашы} жашта.")

Натыйжасы: Менин атым Айдана, жашым 14 жашта.

Эсептөөнү да түз эле кашаанын ичинде жазууга болот:

a = 8
b = 5
print(f"{a} + {b} = {a + b}")

Натыйжасы: 8 + 5 = 13.

5. Сандарды белгилүү тактыкта чыгаруу

f-string аркылуу бөлчөк сандын үтүрдөн кийинки орундарын чектөөгө болот. Python кодунда бөлчөк сан чекит менен жазылат.

баа = 12.56789

print(f"{баа:.2f}")  # 12.57
print(f"{баа:.1f}")  # 12.6
print(f"{баа:.0f}")  # 13
ФорматТүшүндүрмөМисал
{x:.2f}Үтүрдөн кийин 2 орун12.57
{x:.1f}Үтүрдөн кийин 1 орун12.6
{x:.0f}Бүтүнгө жакындатылган көрүнүш13
{x:8.2f}Жалпы туурасы 8 орун, 2 ондук орун12.57
Форматтоодо сан өзгөрмөсүнүн баштапкы мааниси өзгөрбөйт. Болгону экранга чыгарылган көрүнүшү өзгөрөт.

6. format() методу менен форматтоо

f-string'ден тышкары format() методу да колдонулат.

аты = "Бек"
баа = 4.75

текст = "Окуучу: {}, орточо баа: {:.1f}".format(аты, баа)
print(текст)

Натыйжасы: Окуучу: Бек, орточо баа: 4.8.

Жаңы программаларда f-string көп учурда кыска жана түшүнүктүү болгондуктан ыңгайлуу.

7. Практикалык иштер

  1. Жеңил: колдонуучудан эки бүтүн сан алып, алардын суммасын эсептегиле.
  2. Жеңил: колдонуучудан бир бөлчөк сан алып, анын тибин type() менен көрсөткүлө.
  3. Орто: товар баасын жана санын киргизип, жалпы сумманы эсептеп, эки ондук орун менен чыгаргыла.
  4. Орто: аты-жөнүн жана жашын киргизип, f-string аркылуу бир сүйлөм кылып чыгаргыла.
  5. Татаал: үч сабактан алынган бааларды float тибинде киргизип, орточо маанисин эсептегиле жана бир ондук орун менен форматтагыла.

8. Сабакты бышыктоо

  1. int, float жана str эмнени билдирет?
  2. input() функциясы кайсы типтеги маанини кайтарат?
  3. Сапты бүтүн санга айландыруу үчүн кайсы функция колдонулат?
  4. Бөлчөк санга айландыруу үчүнчү?
  5. Санды сапка айландыруу үчүнчү?
  6. f-string кандайча жазылат?
  7. {x:.2f} форматындагы .2f эмнени билдирет?
  8. format() методу эмне үчүн колдонулат?

9. Үй тапшырма

Колдонуучудан эки сан киргизгиле. Бирин float, экинчисин int тибине айландырып, алардын суммасын жана көбөйтүндүсүн эсептегиле. Натыйжаларды f-string менен түшүнүктүү сүйлөм түрүндө чыгаргыла. Бөлчөк натыйжаны эки ондук орун менен форматтагыла.
