Сабактын максаты

Окуучулар ички шарттуу операторлорду жана ички циклдерди колдонушат. break жана continue операторлору аркылуу циклдин аткарылышын башкара алышат.

Күтүлүүчү натыйжалар

  • Ички шарттуу операторду түшүндүрөт.
  • Бир циклдин ичинде экинчи циклди колдонот.
  • break жана continue операторлорунун айырмасын билет.
  • Python тилинде жөнөкөй программа түзөт.

1. Ички шарттуу операторлор

Шарттуу операторлор программанын аткарылышын шартка жараша башкарат. Бир if операторунун ичинде дагы бир if операторун жазууга болот. Бул ички шарттуу оператор деп аталат.

if шарт:
    команда
elif башка_шарт:
    команда
else:
    команда

Мисал 1. Сандын оң жана жуп экенин текшерүү

n = int(input("Санды киргизиңиз: "))

if n > 0:
    if n % 2 == 0:
        print("Оң жуп сан")
    else:
        print("Оң так сан")
else:
    print("Сан оң эмес")

Адегенде сан оңбу деп текшерилет. Эгер оң болсо, экинчи шарт анын жуп же так экенин аныктайт.

2. Ички циклдер (Nested loops)

Бир циклдин ичинде экинчи цикл жайгашса, ал ички цикл деп аталат. Сырткы циклдин ар бир кадамында ички цикл толук аткарылат.

for i in range(1, 4):
    for j in range(1, 4):
        print(i, j)

  • Сырткы цикл i өзгөрмөсүн башкарат.
  • Ар бир i үчүн ички цикл j өзгөрмөсүн 1ден 3кө чейин өзгөртөт.
  • Ички цикл бүткөндөн кийин сырткы цикл кийинки кадамга өтөт.

for i in range(1, 6):

    print()

3. break оператору

break оператору өзү жайгашкан циклдин аткарылышын дароо токтотот.

for i in range(1, 11):
    if i == 5:
        break
    print(i)

i 5ке барабар болгондо цикл токтойт.

4. continue оператору

continue учурдагы кайталоонун калган бөлүгүн өткөрүп, циклдин кийинки кадамына өтөт.

for i in range(1, 11):
    if i == 5:
        continue
    print(i)

Эсиңде болсун: break — циклди толук токтотот; continue — бир кайталоону өткөрүп жиберет.

5. Ички циклдеги break

break жана continue адатта өзү жазылган эң жакын циклге таасир этет.

for i in range(1, 4):
    for j in range(1, 5):
        if j == 3:
            break
        print(i, j)

Бул мисалда j 3 болгондо ички цикл токтойт, бирок сырткы цикл кийинки i маанисине өтөт.

6. Практикалык иштер

  1. Жеңил: 1ден 10го чейинки сандарды чыгарып, 7ге жеткенде break менен токтоткула.
  2. Орто: 1ден 20га чейинки жуп сандарды continue колдонуп өткөрүп жибергиле. Экранга так сандар гана чыксын.
  3. Орто: ички циклди колдонуп, 1ден 5ке чейин жылдызчалардан үч бурчтук түзгүлө.
  4. Татаал: ички циклдерди колдонуп, 1ден 10го чейинки көбөйтүү таблицасын чыгаргыла.
Кеңеш: жуп санды текшерүү үчүн i % 2 == 0 шартын колдонгула.

7. Сабакты бышыктоо

  1. Ички цикл деген эмне?
  2. Сырткы циклдин бир кадамында ички цикл кандай иштейт?
  3. break эмне кылат?
  4. continue эмне кылат?
  5. break менен continue эмнеси менен айырмаланат?

8. Үй тапшырма

Ички циклдерди колдонуп, 1ден 5ке чейинки сандардын көбөйтүү таблицасын түзгүлө. Ошондой эле 1ден 20га чейинки 3кө бөлүнгөн сандарды гана чыгаруучу программа жазгыла.
