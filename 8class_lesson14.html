Сабактын максаты

Окуучулар маалыматтар базасынын таблицасы менен иштеп, SQL тилинин негизги командаларын практикалык мисалдарда колдонушат: таблица түзүү, маалымат кошуу, тандоо, өзгөртүү жана өчүрүү.

Керектүү каражаттар: компьютер жана MySQL же SQL менен иштөөгө ылайыктуу окуу чөйрөсү. Мүмкүнчүлүк болбосо, тапшырмаларды дептерге жазып аткарууга болот.

1. Практикалык иштин шарты

«Mektep» маалыматтар базасында окуучулар тууралуу маалымат сактайбыз. Ар бир окуучуга ID, аты-жөнү жана классы берилет.

2. Маалыматтар базасын жана таблицаны түзүү

CREATE DATABASE Mektep;
USE Mektep;

CREATE TABLE Okuuchular (
    id INT PRIMARY KEY,
    aty VARCHAR(50),
    klass VARCHAR(10)
);

CREATE DATABASE база түзөт, CREATE TABLE таблица түзөт. PRIMARY KEY ар бир жазууну өзүнчө аныктоочу негизги ачкычты көрсөтөт.

3. Маалыматтарды кошуу — INSERT

INSERT INTO Okuuchular (id, aty, klass)
VALUES
(1, 'Айбек', '8-А'),
(2, 'Алина', '8-А'),
(3, 'Нурбек', '8-Б');

Бул команда таблицага үч окуучунун маалыматын кошот.

4. Маалыматтарды тандоо — SELECT

-- Бардык маалыматтарды көрсөтүү
SELECT * FROM Okuuchular;

-- 8-А класстын окуучуларын тандоо
SELECT * FROM Okuuchular
WHERE klass = '8-А';

-- Аты боюнча иреттөө
SELECT * FROM Okuuchular
ORDER BY aty ASC;

5. Маалыматты өзгөртүү — UPDATE

UPDATE Okuuchular
SET klass = '8-Б'
WHERE id = 2;

ID номери 2 болгон окуучунун классы өзгөрөт.

6. Маалыматты өчүрүү — DELETE

DELETE FROM Okuuchular
WHERE id = 3;
Коопсуздук эрежеси: UPDATE жана DELETE командаларында WHERE шартын туура көрсөтүү керек. WHERE жок болсо, таблицадагы бардык жазуулар өзгөрүп же өчүп калышы мүмкүн. Чыныгы маалыматтар базасында иштөөдөн мурда маалыматтын көчүрмөсүн сактагыла.

7. Өз алдынча аткарылуучу тапшырмалар

  1. Okuuchular таблицасына дагы эки окуучуну кошуучу INSERT командасын жазгыла.
  2. 8-Б класстын окуучуларын гана көрсөтүүчү SELECT сурамын түзгүлө.
  3. ID номери 1 болгон окуучунун классын 8-В кылып өзгөрткүлө.
  4. ID номери 2 болгон окуучунун жазуусун өчүрүүчү команданы жазгыла.
  5. Бардык окуучуларды аты боюнча кемүү тартибинде иргегиле.

8. Иштин жыйынтыгы

Практикалык иштин аягында окуучу CREATE TABLE, INSERT, SELECT, WHERE, ORDER BY, UPDATE жана DELETE командаларынын кызматын түшүндүрүп, жөнөкөй сурамдарды өз алдынча түзө алышы керек.
