7-сабак: Программалык камсыздоо жана лицензиялардын түрлөрү

🎯 Сабактын максаты

  • Программалык камсыздоо жөнүндө түшүнүк алуу;
  • Программалык камсыздоонун түрлөрүн айырмалоо;
  • Программалык лицензия деген эмне экенин түшүнүү;
  • Эркин жана эркин эмес программалык камсыздоону айырмалоо;
  • Программаны мыйзамдуу колдонуу эмне үчүн маанилүү экенин түшүнүү.

💻 Программалык камсыздоо деген эмне?

Программалык камсыздоо — компьютердин иштешин камсыз кылган программалардын жыйындысы.

Компьютердеги операциялык система, браузер, тексттик редактор, графикалык редактор жана башка программалар программалык камсыздоого кирет.

Мисалдар:

Windows, Linux, macOS — операциялык системалар.
Google Chrome, Firefox — браузерлер.
Microsoft Word, LibreOffice Writer — тексттик редакторлор.

📚 Программалык камсыздоонун негизги түрлөрү

1. Системалык программалар

Компьютердин негизги иштешин камсыз кылат.

Мисал: Windows, Linux, macOS.

2. Колдонмо программалар

Колдонуучунун конкреттүү иштерин аткарууга жардам берет.

Мисал: Word, Excel, PowerPoint, браузерлер.

3. Программалоо каражаттары

Жаңы программаларды түзүү үчүн колдонулат.

Мисал: Python, Visual Studio Code жана башка программалоо чөйрөлөрү.

📜 Лицензия деген эмне?

Программалык лицензия — программаны кандай шарттарда колдонууга, көчүрүүгө, өзгөртүүгө же таратууга болорун аныктаган эрежелер.

Жөнөкөй мисал:

Эгер программа лицензия боюнча бир компьютерде гана колдонууга уруксат берсе, аны уруксатсыз башка компьютерлерге көчүрүүгө болбойт.
⚠️ Ар бир программаны анын лицензиясында көрсөтүлгөн шарттарга ылайык колдонуу керек.

🟢 Эркин программалык камсыздоо

Эркин программалык камсыздоо — колдонуучуга программаны колдонуу, изилдөө, өзгөртүү жана таратуу боюнча белгилүү эркиндиктерди берген программалык камсыздоо.

Маанилүү: «эркин программалык камсыздоо» сөзсүз түрдө «акысыз программа» дегенди билдирбейт. Бул жерде негизги түшүнүк — колдонуучунун программаны колдонуу жана өзгөртүү эркиндиктери.
Мисал:

GNU/Linux сыяктуу эркин программалык камсыздоолор.

🔓 Open Source деген эмне?

Open Source — программалык камсыздоонун баштапкы коду ачык болуп, лицензиясы уруксат берген шарттарда аны көрүүгө, өзгөртүүгө жана таратууга мүмкүнчүлүк берген ыкма.

Мисал:

Кээ бир Open Source долбоорлорунда программанын баштапкы кодун карап чыгып, аны жакшыртууга салым кошууга болот.

🔴 Эркин эмес программалык камсыздоо

Эркин эмес программалык камсыздоо — колдонуунун, өзгөртүүнүн, көчүрүүнүн же таратуунун айрым укуктары лицензия менен чектелген программалык камсыздоо.

Мисалдар:

Көптөгөн коммерциялык программалар өзүнүн менчик лицензиясы менен тарайт.

Мындай программаларды колдонууда лицензиянын шарттарын сактоо керек.

💰 Акысыз программа менен эркин программаны айырмалоо

Түшүнүк Мааниси
Акысыз программа Программаны акча төлөбөй колдонууга уруксат берилет, бирок анын коду жана башка укуктары чектелиши мүмкүн.
Эркин программалык камсыздоо Лицензиясы колдонуучуга белгилүү программалык эркиндиктерди берет.
Эркин эмес программа Лицензиясы колдонуу, өзгөртүү же таратуу укуктарын чектейт.

📝 Лицензиялардын айрым түрлөрү

Лицензия/модель Кыскача түшүндүрмө
Open Source Баштапкы код лицензиянын шарттарына ылайык жеткиликтүү.
Proprietary Программага болгон укуктар белгилүү бир ээлик кылуучуга таандык жана колдонуу шарттары чектелиши мүмкүн.
Freeware Программаны акысыз колдонууга уруксат берилет, бирок бул сөзсүз Open Source дегенди билдирбейт.
Shareware Программанын чектелген версиясы же сыноо мөөнөтү сунушталышы мүмкүн.
Public Domain Автордук укуктун чектөөлөрү колдонулбаган же тиешелүү укуктардан баш тартылган программалык материалдар болушу мүмкүн.

⚖️ Эмне үчүн лицензияны сактоо керек?

  • Автордун жана укук ээсинин эмгегин урматтоо үчүн;
  • Программаны мыйзамдуу колдонуу үчүн;
  • Уруксатсыз көчүрүүгө жана таратууга жол бербөө үчүн;
  • Программанын колдонуу шарттарын туура түшүнүү үчүн.
⚠️ Интернеттен табылган ар бир программаны каалагандай көчүрүп, өзгөртүп же таратууга болот деп ойлобоо керек. Алгач анын лицензиясын текшерүү зарыл.

✏️ Практикалык тапшырма

Төмөнкү программаларды карап чыгып, алардын кайсы түргө жакын экенин аныктагыла:

1. Windows
2. GNU/Linux
3. Акысыз, бирок баштапкы коду жабык программа
4. Open Source программасы

Ар бир мисал боюнча анын лицензиялык шарттарын өз алдынча текшерип, эмне үчүн ошол категорияга кирерин түшүндүргүлө.
