Сабактын максаты

Окуучулар Python тилиндеги сап (string) түшүнүгүн өздөштүрүшөт. Саптагы символдорго индекс аркылуу кайрылууну, үзүм алууну, саптарды бириктирүүнү, салыштырууну жана негизги сап методдорун колдонууну үйрөнүшөт.

Күтүлүүчү натыйжалар

  • Саптык маалыматтын өзгөчөлүгүн түшүндүрөт.
  • Саптын узундугун len() менен аныктайт.
  • Символдорго индекс жана үзүм аркылуу кайрылат.
  • Саптарды бириктирет жана салыштырат.
  • upper(), lower(), strip(), replace(), split(), join() методдорун колдонот.

1. Сап (string) деген эмне?

Сап — символдордун иреттелген тизмеги. Сапка тамгалар, цифралар, боштуктар жана атайын белгилер кириши мүмкүн. Python тилинде сап тырмакчага алынып жазылат.

aty = "Айжан"
mektep = '№35 мектеп'
kabар = "Python тилин үйрөнүп жатам!"

print(aty)
print(mektep)
print(kabar)
Эсиңде болсун: сапты бир тырмакча ('...') же кош тырмакча ("...") менен жазууга болот. Экөөнүн негизги кызматы бирдей.

2. Саптын узундугу жана индекстери

Саптагы символдор белгилүү бир тартипте жайгашат. Python тилинде биринчи символдун индекси 0 болот. Терс индекс саптын аягынан санайт.

soz = "PYTHON"

print(soz[0])   # P
print(soz[2])   # T
print(soz[-1])  # N
print(len(soz)) # 6
СимволPYTHON
Индекс012345

len() функциясы саптагы символдордун санын эсептейт. Боштук да символ катары эсептелет.

Маанилүү: саптар өзгөртүлбөй турган (immutable) маалымат тиби. Мисалы, soz[0] = "B" деп түздөн-түз өзгөртүү мүмкүн эмес. Өзгөртүлгөн жаңы сап түзүү керек.

3. Саптан үзүм алуу (slicing)

Үзүм саптын белгилүү бөлүгүн алуу үчүн колдонулат. Жазылышы: soz[башталышы:аягы:кадам]. Аяктоо индекси алынган бөлүккө кирбейт.

soz = "INFORMATIKA"

print(soz[0:4])  # INFO
print(soz[4:8])  # RMAT
print(soz[:5])   # INFOR
print(soz[5:])   # MATIKA
print(soz[::2])  # I F R A I A белгилеринин ар бир экинчиси

Сапты тескери тартипте алуу:

soz = "PYTHON"
print(soz[::-1])

Натыйжасы: NOHTYP.

4. Саптарды бириктирүү жана кайталоо

+ оператору саптарды бириктирет, ал эми * оператору сапты көрсөтүлгөн санда кайталайт.

aty = "Айжан"
familiya = "Осмонова"

toluk_aty = aty + " " + familiya
print(toluk_aty)

print("Салам! " * 3)

Натыйжасы:

Айжан Осмонова
Салам! Салам! Салам!

5. Саптар менен иштөөчү негизги методдор

Метод — белгилүү бир объект менен иш аткаруучу функция. Сап методдору саптын абалын текшерүүгө же анын негизинде жаңы сап түзүүгө жардам берет.

МетодКызматыМисал
upper()Бардык тамгаларды баш тамгага өткөрөт"Salam".upper() → SALAM
lower()Бардык тамгаларды кичине тамгага өткөрөт"SALAM".lower() → salam
title()Ар бир сөздүн баш тамгасын чоңойтот"hello world".title() → Hello World
strip()Башындагы жана аягындагы боштуктарды алып салат" test ".strip() → test
replace(a,b)Саптагы a бөлүгүн b менен алмаштырат"көк".replace("к","ж") → жөж
find()Изделген бөлүктүн биринчи индексин табат; табылбаса -1 берет"мектеп".find("к") → 2
count()Белги же бөлүк канча жолу кездешерин санайт"апа".count("а") → 2
soz = "  Python тили  "

print(soz.strip())
print(soz.upper())
print(soz.lower())

tekst = "Мен Python үйрөнөм"
print(tekst.replace("Python", "программалоону"))
Методдор баштапкы сапты өзгөртпөйт, адатта натыйжа катары жаңы сап кайтарат. Натыйжаны сактоо үчүн аны өзгөрмөгө ыйгаргыла.

6. Сапты бөлүү жана кайра бириктирүү

split() сапты бөлүктөргө бөлүп, тизме кайтарат. join() тизмедеги саптарды бириктирет.

aty_jonu = "Айбек Токтосунов"
boluktor = aty_jonu.split()

print(boluktor)
print("-".join(boluktor))

Натыйжасы:

['Айбек', 'Токтосунов']
Айбек-Токтосунов

Мисалы, боштук менен берилген сөздөрдү үтүр аркылуу бириктирүүгө болот:

сөздөр = ["Python", "маанилүү", "тил"]
текст = ", ".join(сөздөр)
print(текст)

7. Саптарды салыштыруу жана иргөө

Саптарды ==, !=, <, > операторлору менен салыштырууга болот. Салыштыруу символдордун коддору жана тартиби боюнча жүргүзүлөт. Чоң жана кичине тамгалар айырмаланат.

print("alma" == "alma")  # True
print("alma" != "Alma")  # True
print("abc" < "abd")     # True

Сөздөр тизмесин алфавиттик тартипке келтирүү үчүн sort() же sorted() колдонулат.

sozder = ["алма", "өрүк", "банан"]
sozder.sort()
print(sozder)
Эскертүү: саптарды салыштырууда тамгалардын регистри эске алынат. Кыргыз тамгалары бар тексттерди алфавит боюнча так иргөөдө атайын эрежелер талап кылынышы мүмкүн.

8. Практикалык иштер

  1. Жеңил: аты-жөнүңөрдү сап катары сактап, экранга баш тамгалар менен жана кичине тамгалар менен чыгаргыла.
  2. Орто: "ИНФОРМАТИКА" деген саптан биринчи 4 символду жана акыркы 5 символду өз-өзүнчө чыгаргыла.
  3. Орто: колдонуучудан сүйлөм алып, анын узундугун эсептегиле жана боштуктарды алып салган вариантын чыгаргыла.
  4. Орто: "Мен Python үйрөнөм" сүйлөмүндөгү Python сөзүн программалоо деген сөзгө алмаштыргыла.
  5. Татаал: колдонуучудан боштук менен бөлүнгөн үч сөз алып, split() аркылуу бөлүп, аларды дефис менен бириктиргиле.

10. Үй тапшырма

Колдонуучудан аты-жөнүн киргизгиле. Аны ашыкча боштуктардан тазалап, баш тамга менен жана кичине тамга менен чыгаргыла. Аты-жөнүн сөздөргө бөлүп, ортосуна дефис коюп кайра бириктиргиле. Андан соң саптын узундугун эсептеп, биринчи жана акыркы символун экранга чыгаргыла.
