Клавиатура жана чычкан менен иштөө

Информатика

🎯 Сабактын максаты

  • Клавиатуранын негизги баскычтарын үйрөнүү.
  • Баскычтардын айкалышын туура колдонуу.
  • Чычкан менен иштөөнүн негизги аракеттерин өздөштүрүү.
  • Текст терүү көндүмдөрүн өнүктүрүү.

1. Клавиатура деген эмне?

Клавиатура — компьютерге текст, сандар жана буйруктарды киргизүүчү түзүлүш.

Клавиатура аркылуу маалымат жазабыз, программаларды башкарабыз жана компьютер менен иштейбиз.

2. Клавиатуранын негизги баскычтары

БаскычКызматы
EnterЖаңы сапка өтүү же буйрукту аткаруу.
ShiftБаш тамга же кошумча белгини терүү.
Caps LockБаш тамгалар режимин күйгүзүү жана өчүрүү.
BackspaceКурсордун сол жагындагы белгини өчүрүү.
DeleteКурсордун оң жагындагы белгини өчүрүү же тандалган объектти жок кылуу.
Багыттоочу жебелерКурсорду өйдө, төмөн, оңго жана солго жылдыруу.
SpaceСөздөрдүн ортосуна боштук коюу.
TabКийинки талаага өтүү же чегинүү жасоо.

3. Баскычтардын айкалышы

Эки же андан көп баскычты бир убакта басуу аркылуу атайын буйруктарды аткарууга болот.

Ctrl + C — тандалган маалыматты көчүрүү.
Ctrl + V — көчүрүлгөн маалыматты коюу.
Ctrl + X — тандалган маалыматты кесип алуу.
Ctrl + Z — акыркы аракетти артка кайтаруу.
Ctrl + A — бардык маалыматты тандоо.
Ctrl + S — документти сактоо.

4. Чычкан менен иштөө

Компьютердик чычкан — экрандагы көрсөткүчтү башкаруучу түзүлүш.

  • Бир жолу чыкылдатуу: объектти тандоо.
  • Эки жолу чыкылдатуу: файлды же программаны ачуу.
  • Оң баскычты басуу: кошумча менюну ачуу.
  • Сүйрөө: объектти кармап башка жерге жылдыруу.
  • баракты өйдө же төмөн жылдыруу.

5. Практикалык иш 💻

Тапшырма 1. Тексттик редакторду ачып, төмөнкү текстти тергиле:

Менин атым __________. Мен 7-класста окуйм. Информатика — кызыктуу предмет.
  1. Enter баскычы менен жаңы сапка өтгүлө.
  2. Caps Lock аркылуу баш тамгаларды тергиле.
  3. Shift аркылуу кошумча белгилерди киргизгиле.
  4. Ctrl + A менен текстти толук белгилегиле.
  5. Ctrl + C жана Ctrl + V аркылуу текстти көчүргүлө.
  6. Ctrl + Z менен акыркы аракетти артка кайтаргыла.
  7. Ctrl + S менен документти сактагыла.

Тапшырма 2. Чычкан менен файлды тандап, эки жолу чыкылдатып ачкыла. Андан кийин аны башка папкага сүйрөп жылдыргыла.

6. Өзүңдү текшер 🧠

  1. Клавиатура эмне үчүн колдонулат?
  2. Enter баскычынын кызматы кандай?
  3. Caps Lock эмне кылат?
  4. Backspace кайсы белгини өчүрөт?
  5. Ctrl + C кандай буйрук?
  6. Ctrl + V кандай буйрук?
  7. Ctrl + Z эмне үчүн колдонулат?
  8. Чычкан менен эки жолу чыкылдатуу эмне кылат?
  9. Объектти башка жерге жылдыруу кандай аталат?
  10. Чычкандын дөңгөлөгү эмне үчүн керек?

📌 Сабакты жыйынтыктоо

Клавиатура маалымат киргизүү үчүн, ал эми чычкан экрандагы объекттерди башкаруу үчүн колдонулат. Баскычтардын айкалышы компьютерде иштөөнү тездетет.
