Функцияны чакыруу

Функция аныкталгандан кийин аты жана кашаасы менен чакырылат: salamdash(). Чакырмайынча денеси аткарылбайт.

Аныктоо ≠ чакыруу.

Параметр жана аргумент

Параметр — функция аныкталганда жазылган өзгөрмө. Аргумент — чакырганда берилген чыныгы маани.

def koshuu(a,b); koshuu(4,6)

return оператору

return функциядан жыйынтык маанини кайтарат. Кайтарылган маанини өзгөрмөгө сактап, башка эсептөөлөрдө колдонсо болот.

def koshuu(a,b): return a+b

lambda функциясы

lambda — кыска, аты жок функция түзүүгө мүмкүндүк берет. Мисал: kvadrat = lambda x: x*x.
